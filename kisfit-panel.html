Пароли тестировщиков

Скачивание APK с сайта больше не требует пароля. Этот список можно оставить для служебного доступа к POST /api/tester/login. В списке пароли не показываются — только подпись и дата. Старый пароль из SITE_DOWNLOAD_PASSWORD в .env при старте сервера один раз импортируется в список.

Рекламные баннеры

Баннер — одна картинка 1080×360 px (PNG/JPEG/WebP) с текстом внутри. При нажатии в приложении открывается указанная ссылка. На одно место можно добавить несколько баннеров — они будут автоматически перелистываться каждые 10 секунд.

Реклама на карте

На карте видна только картинка, без подложки. По нажатию открывается карточка с названием, описанием и ссылкой. Лучше PNG с прозрачным фоном от 256 px.

Оформление страницы турнира

Выберите готовую тему и подправьте детали — справа сразу видно, как страница будет выглядеть в приложении. Тема «Смелость» включает свою вёрстку (бегущая строка, лаймовые квадраты, Live Result, пин на карте). Цвета после выбора можно менять — вёрстка останется. Сохраните турнир, чтобы увидеть это в приложении. Позже сюда можно будет подключать кастомные дизайн-паки с картинками.
